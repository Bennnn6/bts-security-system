Pasang aplikasi BACS langsung ke menu aplikasi (App Drawer) smartphone Anda sekarang.
METODE 1 (REKOMENDASI INSTAN)
Scan QR Code dengan HP

Buka kamera HP atau scanner untuk langsung membuka aplikasi di smartphone Anda.

Pastikan HP dan Laptop terhubung di Wi-Fi / Hotspot yang sama.
Mau akses di luar rumah/jaringan? Jalankan file BACS_Bagi_Akses_Publik.bat di laptop untuk mendapatkan link internet publik HTTPS resmi.
Petunjuk Pemasangan di Layar Utama HP

Aplikasi BACS berbasis Progressive Web App (PWA) berjalan native tanpa address bar browser.

Pengguna Android (Google Chrome)
  1. Scan QR Code atau ketik alamat {{ local_url }} di browser Google Chrome di HP.
  2. Akan muncul banner di bawah: "Tambahkan BACS ke Layar Utama". Jika tidak muncul, ketuk Titik Tiga (⋮) di pojok kanan atas browser.
  3. Pilih menu "Instal aplikasi" atau "Tambahkan ke Layar Utama".
  4. Ketuk Instal. Aplikasi langsung terpasang di menu HP dengan ikon resmi BACS!
Pengguna iPhone / iOS (Safari)
  1. Buka link {{ local_url }} menggunakan browser Safari.
  2. Ketuk tombol Bagikan (Share / Kotak dengan panah atas) di bagian bawah layar.
  3. Pilih "Add to Home Screen" (Tambahkan ke Layar Utama) lalu ketuk Add.
Metode 2: Source Code Native Android (.apk)
